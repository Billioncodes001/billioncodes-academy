# Course-content sourcing

No paid content-retrieval subscription is required for the initial library. Academic search subscriptions do not normally grant redistribution or resale rights. Do not scrape Udemy, bypass paywalls, download standard-licence YouTube videos for rehosting, or treat search results as permission.

## Sources checked on 11 September 2026

- [Open Textbook Library discovery API](https://open.umn.edu/opentextbooks/discovery) offers public bibliographic metadata under CC0. Use `npm run content:discover -- database` to list computer-science candidates reported as Attribution, Attribution-ShareAlike or CC0. This read-only tool requires no account or API key, never downloads course files, and never publishes automatically. The original item's licence takes precedence over the catalogue.
- [Database Design, 2nd Edition](https://opentextbc.ca/dbdesign01/front-matter/preface/) credits Adrienne Watt and Nelson Eng and uses CC BY 4.0 except where otherwise noted. Review chapter-level exclusions before importing the full PDF. Preserve credits, source, licence and any changes.
- [Think Python, 3rd Edition](https://greenteapress.com/wp/think-python-3rd-edition/) is Allen B. Downey's work under CC BY-NC-SA 4.0. The Academy links to its official page only.
- [CS50x](https://cs50.harvard.edu/x/license/) is CC BY-NC-SA 4.0. Link to the official video/course site; do not bundle it as a paid Billion Codes course without separate permission.
- [OpenStax's computer-science textbook](https://openstax.org/books/introduction-computer-science/pages/preface) uses CC BY-NC-SA 4.0 and has specific attribution/branding conditions. It is an external reference link, not rehosted stock course content.
- [Saylor licensing](https://www.saylor.org/LicensingInformation) distinguishes original framing content, third-party resources and excluded examinations. Check the exact asset, not just the site's footer. A Saylor account or certificate does not grant reuse of exam banks.

## Intake checklist for every hosted resource

1. Record title, creator, publisher, edition/version and original HTTPS source.
2. Retain licence text/link and evidence of permission for this exact PDF/video.
3. Check embedded illustrations, clips, diagrams, trademarks and third-party exceptions.
4. Confirm whether commercial use, modification and redistribution are permitted. Do not label NC material as suitable for a commercial course simply because the app's download is free.
5. Preserve source attribution and disclose modifications. Apply required share-alike terms to adaptations, not automatically to unrelated app code.
6. Review instructional quality, accessibility, captions and suitability for the target syllabus.
7. For PDFs, inspect the actual file before staff upload. File signature checks are not antivirus. For video, use an authorized source file and retain captions.
8. Publish the resource only after a human review. Keep the evidence with operating records; the current API's rights-confirmation header is an operator assertion, not an automated licence decision.

The Open Shelf currently contains four external resource links with credits. It does not claim a partnership with any provider and makes no promise of synced external completion, qualifications or certificates. Hosted course imports, captions and a full publishing UI are subsequent work, not silently represented as complete.
